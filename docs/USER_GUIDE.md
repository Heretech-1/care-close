# CareClose: Посібник користувача та опис функціоналу

**CareClose** — це персональний цифровий помічник для піклування про літніх батьків та рідних. Додаток поєднує турботу дорослих дітей, максимальну простоту для людей старшого віку та можливість залучати сусідів, доглядальниць чи медсестер без ризику для схеми лікування.

---

## 🌟 Ключова ідея та філософія

Більшість медичних додатків складні, вимагають реєстрацій на хмарних серверах, надсилають дрібні незрозумілі push-сповіщення та спамлять рекламою.
**CareClose працює інакше:**
1. **Безсерверність та повна приватність:** Ніяких сторонніх серверів чи платних підписок. Усі дані шифруються військовим стандартом **AES-256-GCM** і синхронізуються через звичайну папку Google Drive вашої родини.
2. **Нуль зусиль для літньої людини:** Телефон літнього родича перетворюється на спокійний смарт-годинник із підказками. При настанні часу прийому екран сам вмикається, звучить рідний голос дитини або м'який сигнал, показується велике кольорове фото таблеток та одна велика кнопка.
3. **Гнучкий ритм замість жорстких годин:** Більшість ліків п'ються «після сніданку» або «після обіду». CareClose прив'язує завдання до життєвих якорів дня літньої людини.
4. **Турбота без нав'язливого контролю:** Дорослий опікун бачить, чи активний телефон, чи є зв'язок, який заряд акумулятора, і отримує тривожне сповіщення лише якщо дедлайн пропущено, а телефон був у мережі.
5. **Командний догляд із захистом від помилок:** До основного опікуна (донька/син) можна легко підключити помічника (сусідка, медсестра, сиділка, волонтер) через швидкий QR-код із безпечним рівнем доступу (тільки перегляд і відмітка виконання).

## 👥 Ролі в системі

### 1. 🧓 Літня людина (Підопічний)
Режим призначений для встановлення на телефон мами, тата чи бабусі/дідуся.

* **Надвеликий контрастний екран:** Чіткий великий годинник, дата, статус дня та фокус на поточному завданні. Жодних меню, налаштувань чи зайвих кнопок.
* **Наочність ліків:** Фотографія блістера/таблетки крупним планом та графічні кружечки кількості (наприклад, 💊 2 шт.).
* **Будильник поверх заблокованого екрана:** Спрацьовує навіть якщо телефон заблоковано або стоїть у беззвучному режимі.
* **Голос рідної людини:** Замість неприємного синтезатора мови звучить теплий аудіозапис доньки чи сина: *"Мамо, випий, будь ласка, рожеву пігулку від тиску"*.
* **Одна велика дія:** Кнопка «ПРИЙНЯЛА / ЗРОБИЛА» (або «ПРИЙНЯВ / ЗРОБИВ» для тата).
* **Захист від випадкових натискань:** Після натискання з'являється 5-секундний таймер «Скасувати», якщо кнопку було зачеплено випадково.
* **Кнопка швидкого виклику:** Одне торкання «Зателефонувати доньці» (або сину) одразу відкриває дзвінок на перевірений номер.
* **Віджет на робочий стіл (Glance):** Поточне завдання та час наступного прийому прямо на домашньому екрані Android.

### 2. 📱 Головний опікун (Дорослий / Адміністратор)
Встановлюється на телефон доньки, сина, онуки або опікуна, який координує догляд.

* **Повний контроль розкладу:**
  * Створення та редагування ліків, вимірювань (тиск, цукор), гігієни та прийомів їжі.
  * Гнучкі режими часу: точний час (наприклад, `08:00`) або відносний час після якоря (наприклад, `через 30 хв після сніданку`).
  * Фотографування ліків прямо на камеру телефону з автосинхронізацією на телефон батьків.
  * Запис власного голосу на диктофон для кожного нагадування.
* **Розумна аптечка (Інвентар):**
  * Облік залишку таблеток у блістерах та упаковках.
  * Автоматичне списання при кожному підтвердженні прийому.
  * Завчасне попередження: «Залишилося на 3 дні, час купити в аптеці».
* **Телеметрія та статус пристрою:**
  * Заряд батареї телефону мами/тата та статус підключення до зарядного пристрою.
  * Рівень сигналу Wi-Fi / мобільного інтернету.
  * Час останнього виходу на зв'язок («🟢 Мама онлайн (5 хв тому)» або «🔴 Не виходила на зв'язок (70 хв тому)»).
* **Підтримка кількох підопічних (Multi-Elder):**
  * Можливість перемикатися в один клік у шапці екрана між картками: наприклад, «Мама» та «Тато».
  * Окремі розклади, аптечки та журнали подій для кожного з батьків.
* **Безпечна передача доступу помічникам:**
  * Генерація спеціального безпечного QR-коду для сусідки чи медсестри.

---

### 3. 🤝 Допоміжний опікун / Помічник (Сусідка, Медсестра, Сиділка, Волонтер)
Спеціально розроблений безпечний режим для людей, які фізично провідують літню людину або живуть поруч.

* **Швидке підключення за 10 секунд:** Достатньо відсканувати QR-код з екрана головного опікуна або ввести код вручну.
* **Безпечний режим (Safe Read-Only):**
  * Помічник **не може** випадково змінити дозування, видалити ліки чи поламати розклад. Кнопки редагування повністю заблоковані.
* **Моніторинг виконання:** Помічник бачить актуальний розклад на сьогодні: які ліки вже випито, а які заплановані на найближчий час.
* **Відмітка прийому особисто:**
  * Якщо помічник сам дав ліки, він натискає кнопку, наприклад: «Відмітити як виконано (Медсестра)».
  * У системі формується підпис із роллю та ім'ям: *«✓ Виконала медсестра (Оксана)»* або *«✓ Перевірила сусідка (Галина)»*.
  * Головний опікун одразу бачить у своєму додатку, хто саме проконтролював прийом.
* **Швидкий зв'язок із головним опікуном:** Кнопка екстреного дзвінка доньці/сину в один дотик у разі погіршення самопочуття підопічного.

## 🇺🇦 Жива українська мова та врахування статі

Додаток говорить живою, теплою українською мовою з граматичним узгодженням закінчень:
* **Для Мами / Бабусі:** дієслова узгоджуються у жіночому роді («Мама прийняла ліки», «не виходила на зв'язок»).
* **Для Тата / Дідуся:** у чоловічому роді («Тато прийняв ліки», «не виходив на зв'язок»).
* **Природні родинні кнопки:**
  * У доньки: *«Відмітити як виконано (Дала ліки)»* -> примітка: *«Дала особисто (Донька)»*.
  * У сина: *«Відмітити як виконано (Дав ліки)»* -> примітка: *«Дав особисто (Син)»*.
  * У медсестри: *«Відмітити як виконано (Медсестра)»* -> примітка: *«Виконала медсестра (Оксана)»*.
  * У сусідки: *«Відмітити як виконано (Сусідка)»* -> примітка: *«Перевірила сусідка (Ніна)»*.

## 🔒 Архітектура синхронізації та автономність

* **Повна робота без Інтернету:** Усі нагадування, будильники, фотографії та розклади зберігаються локально в базі даних Room на пристрої літньої людини. Навіть при повному відключенні світла чи зв'язку всі будильники продзвенять точно вчасно.
* **Конфліктно-вільні події (CRDT Event Log):**
  * Кожен пристрій має власний унікальний `deviceId`.
  * Усі відмітки (прийом мамою, перевірка сиділкою, відмітка донькою) записуються окремими підписаними файлами в підпапки Google Drive.
  * Жоден запис не перезаписує чужий — вони автоматично об'єднуються локально в хронологічному порядку.
* **Економія батареї (Predictive Polling):**
  * Додаток не тримає постійних веб-сокетів. Телефон опитує Google Drive тільки у вікна очікуваних подій, що береже заряд батареї смартфона.

## 📋 Системні вимоги

* **Операційна система:** Android 8.0 (Oreo, API 26) або вище.
* **Цільова версія:** Android 15 (Vanilla Ice Cream, API 35).
* **Спеціальні дозволи (чекліст в додатку):**
  * Дозвіл на точні будильники (`USE_EXACT_ALARM` / `SCHEDULE_EXACT_ALARM`).
  * Показ поверх інших вікон (`SYSTEM_ALERT_WINDOW`) для гарантованого пробудження екрана.
  * Вимкнення оптимізації батареї (Doze mode whitelist) для надійної роботи у фоні.
  * Доступ до сповіщень та автостарту після перезавантаження (`RECEIVE_BOOT_COMPLETED`).
