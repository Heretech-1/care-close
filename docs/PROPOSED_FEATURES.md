# Майбутні концептуальні функції CareClose

У цьому документі зафіксовано концепції розширення функціоналу, заплановані для майбутніх релізів.

---

## 1. Замір показників здоров'я (тиск, пульс, рівень цукру, температура)

### Мета
Для багатьох людей літнього віку (особливо при гіпертонії, серцево-судинних захворюваннях та цукровому діабеті) важливо не просто прийняти ліки чи виміряти показник, а зберегти точне числове значення для лікаря та опікуна.

### Концепція реалізації
1. **Новий тип завдання або розширення `TaskRule`**:
   - `TaskType.HEALTH_CHECK` або прапорець `requiresMeasurement: Boolean`.
   - Визначення типу вимірювання:
     - `BLOOD_PRESSURE` (Артеріальний тиск + пульс, напр. `130/80`, `72`).
     - `BLOOD_GLUCOSE` (Цукор у крові, напр. `5.6 ммоль/л`).
     - `TEMPERATURE` (Температура тіла, напр. `36.6 °C`).
     - `WEIGHT` (Вага, напр. `74.5 кг`).
2. **Інтерфейс підопічного**:
   - При натисканні «Виконано» відкривається велике, спрощене вікно з великими кнопками цифр (цифрова клавіатура з контрастними клавішами) або швидкими шаблонами.
   - Можливість пропустити введення чисел (якщо виміряти не вдалося або немає апарата).
3. **Відображення для опікуна**:
   - У таймлайні дня картка виводить: `✅ Виміряно: 125/80 мм рт. ст., пульс 68 уд/хв`.
   - Журнал вимірювань за тиждень/місяць із підсвічуванням небезпечних відхилень (наприклад, тиск > 150 або цукор > 10).
   - Експорт звіту у формат для сімейного лікаря.

---

## 2. Ранкове експрес-опитування самопочуття («Як ви почуваєтесь?»)

### Мета
Опікун отримує технічну телеметрію (заряд, інтернет, звук), проте не має оперативного розуміння фізичного та емоційного стану підопічного без прямого телефонного дзвінка.

### Концепція реалізації
1. **Періодичність і показ**:
   - З'являється один раз на добу (наприклад, вранці під час підтвердження першого якоря дня або після першого розблокування екрана).
2. **Інтерфейс підопічного (1 дотик)**:
   - Лагідний великий діалог або картка на головному екрані:
     - 🟢 **Все добре / Гарний настрій** (`WELLNESS_GOOD`)
     - 🟡 **Так собі / Втома або слабкість** (`WELLNESS_FAIR`)
     - 🔴 **Погано / Щось болить** (`WELLNESS_POOR`)
   - Можливість додати швидку позначку (наприклад, «болить голова», «тиск», «погано спав(-ла)»).
3. **Реакція системи**:
   - Записується ідемпотентна подія `CareEventType.WELLNESS_LOGGED`.
   - Якщо стан 🔴 («Погано»), на пристрої опікуна з'являється високий пріоритет сповіщення:
     `⚠️ Мама зазначила, що почувається погано. Зателефонуйте, щоб перевірити стан.`
   - У щоденному дашборді статус самопочуття відображається у блоці присутності підопічного.
